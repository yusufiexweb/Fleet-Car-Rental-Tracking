# Fleet & Car Rental Tracking // Vehicle Management & Telemetry UI


A high-performance, professional dashboard and UI portfolio concept engineered for car rental companies, fleet management systems, and vehicle telemetry monitoring. Built with a sleek modern dark-mode aesthetic and responsive architecture.

---

## Key Architectural Features
- **Fleet Control Aesthetic:** High-contrast dark-mode interface featuring vehicle status summary cards, booking tracking tables, and live telemetry metric widgets.
- **Pure Vanilla JavaScript & Tailwind:** Zero heavy dependencies to guarantee lightning-fast page loading and rapid DOM manipulation.
- **Fully Responsive Layout:** Seamlessly optimized across mobile, tablet, and high-resolution desktop viewports.

---

## Technology Stack
- **Markup:** HTML5 (Semantic & Accessible)
- **Styling:** Tailwind CSS (Utility-first framework)
- **Scripting:** Pure Vanilla JavaScript (ES6+)
